# VSLike Game Guidelines

## 1. 버전 관리 및 트러블슈팅 동기화 규칙
- 수정 작업 및 버그 해결 시 **패치 버전(Patch Version)**을 우선적으로 1씩 증가시키며 관리합니다 (`0.00.01` -> `0.00.02` -> ...).
- **릴리즈 버전(Release Version)** 및 **메이저 버전(Major Version)**은 작업자가 직접 지정했을 때만 변경합니다.
- 트러블슈팅 문서(`Doc/트러블슈팅 수정사항.xlsx`)의 `진행상태(완료, 테스트요청, 수정중 등)`는 **작업자가 직접 지정**한 값을 최우선으로 존중하며, 커밋 시 자동으로 `GameManager.cs`의 OnGUI 버전/리스트와 동기화되도록 유지합니다.

## 2. 파일 인코딩 규칙
- 모든 C# 스크립트(`.cs`)는 Visual Studio 및 Unity 한글 깨짐 방지를 위해 반드시 **UTF-8 with BOM** 인코딩으로 저장합니다.
